# Как внести вклад

[![CONTRIBUTING in English](https://img.shields.io/badge/CONTRIBUTING-english-informational)](CONTRIBUTING.md)

Спасибо, что нашли время. Это маленький шуточный проект, так что планка простая: должно остаться
смешным, остаться типизированным и по-прежнему проходить CI.

## Установка

```bash
uv sync --group dev
uv run pre-commit install
```

## Перед тем как открыть пул-реквест

Прогоните то же, что гоняет CI:

```bash
uv run pytest
uv run ruff check . && uv run ruff format --check api config tests
uv run mypy .
```

Сообщения коммитов — по [Conventional Commits](https://www.conventionalcommits.org/), как и вся
текущая история: `feat(i18n): ...`, `fix(urls): ...`, `refactor(docker): ...`.

Один пул-реквест — одна тема. Если меняете поведение, добавьте или поправьте тест на него.

## Добавление своего языка

Самый полезный вклад здесь — новая локаль. Фразы это обычный JSON, по файлу на локаль в
[`api/phrases/data/`](api/phrases/data): два настроения × три типа дня × два решения, и ни один
из двенадцати списков не может быть пустым:

```json
{
  "chill":  { "normal":  { "yes": ["..."], "no": ["..."] },
              "friday":  { "yes": ["..."], "no": ["..."] },
              "weekend": { "yes": ["..."], "no": ["..."] } },
  "savage": { "normal":  { "yes": ["..."], "no": ["..."] },
              "friday":  { "yes": ["..."], "no": ["..."] },
              "weekend": { "yes": ["..."], "no": ["..."] } }
}
```

1. Скопируйте `api/phrases/data/en.json` в `api/phrases/data/<code>.json` и переведите.
2. Добавьте `<code>` в литерал `Lang` в [`api/schemas.py`](api/schemas.py) — он единственный
   источник правды и для валидации, и для OpenAPI-схемы.
3. Добавьте `<code>` в `SUPPORTED_LANGS` в
   [`tests/test_phrases_loading.py`](tests/test_phrases_loading.py) и в `LANGS` в двух других
   тестовых модулях. После этого структура нового файла проверяется тестами автоматически.

Структура валидируется при загрузке, так что кривой или неполный файл упадёт сразу, а не будет
молча отдавать поломанные ответы.

И одно замечание перед тем, как переводить: фразы здесь и есть вся шутка. Переводите тон, а не
слова — дословный перевод английской остроты обычно не выстреливает.

## Как сообщить о баге

Заведите issue с запросом, который отправляли, и ответом, который получили. Если речь про
развёрнутый инстанс, идеально — вывод `curl -i`.
